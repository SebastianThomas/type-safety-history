Type Safety History API

The canonical machine-readable contract is the OpenAPI 3.1 document.

Protected requests use Authorization: Bearer <token>. Viewer tokens can read review material; curator tokens can mutate scholarly state; admin tokens manage accounts.

Interfaces

Corpus dashboard · Proof graph · Optional review · Prometheus metrics

Safety model

Local-ML results are published with an explicit machine_classified label, confidence, classifier version and source-evidence provenance. Optional review upgrades the label to curator_approved. Source text is not returned by statistics or public timeline endpoints, and local ML never calls a hosted inference service.
